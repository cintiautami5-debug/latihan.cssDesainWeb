Mengenal Dasar-Dasar CSS untuk Pemula

Ditulis oleh Dosen Pengampu | 23 November 2026 | Kategori: CSS | 12 komentar

CSS (Cascading Style Sheets) adalah bahasa yang digunakan untuk mengatur tampilan dokumen HTML. Jika HTML ibarat kerangka bangunan, maka CSS adalah cat, dekorasi, dan tata letak ruangannya. Pepatah para desainer

Konsep yang Akan Dipelajari

  • Selector (tag, class, id)
  • Warna dan latar belakang
  • Tipografi dan font
  • Box model (margin, border, padding)
  • Layout (display, float, flexbox, grid)

Langkah Belajar

  1. Pahami struktur HTML terlebih dahulu.
  2. Hubungkan file CSS dengan HTML.
  3. Coba ubah warna dan ukuran teks.
  4. Atur jarak antar elemen.
  5. Susun tata letak halaman.

Contoh Kode

Berikut contoh aturan CSS sederhana:

h1 {
  color: navy;
  font-size: 32px;
}

Pada contoh di atas, h1 adalah selector, sedangkan color adalah properti.
